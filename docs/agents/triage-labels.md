# Triage labels

Engineering skills use the following canonical role names directly in local
ticket `Status:` fields.

| Canonical role | Tracker label | Meaning |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | Maintainer evaluation is required. |
| `needs-info` | `needs-info` | More information is required. |
| `ready-for-agent` | `ready-for-agent` | Fully specified and ready for implementation. |
| `ready-for-human` | `ready-for-human` | Human implementation or judgment is required. |
| `wontfix` | `wontfix` | The issue will not be actioned. |
