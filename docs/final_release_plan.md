## 项目与文档整理规则

- 只保留两个发布方向，不把历史实验列为当前待办。
- 当前入口：README → current_status → 本总纲 → optimization_roadmap。
- 历史实验代码、机器报告、哈希绑定路径保留；不做破坏可复算性的“美化搬家”。
- 旧长版状态/路线图可由整理前的 Git 提交恢复，见分支清单。它们不是当前执行指令。
- 不清空模型缓存、catalog、原始标注、忽略的实验输出或用户 stash；没有删除这些资料。
- 方案一只带它本来已有的可选实验，不整体合并 llm；方案二不反向改写方案一默认。
- 不读取、复制、提交 API key。当前整理与验证不新增付费调用。
- 阅读旧工作流时，冻结状态优先于旧文档里的“下一步”。
