## Supporting evidence

Historical `*_evidence.md`, `*_evidence.json` and `*_reports/` retain the
measurements and decisions supporting the implementation. Paths and hashes are
preserved for reproducibility; old experiment outcomes do not describe the current
default unless the current report says so. The current final measurements are
indexed in `delivery_reports/`.
